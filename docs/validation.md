# 验证报告

这份文档记录 `slopestab` 对得上哪些数、对不上多少、以及为什么。所有数字都能用仓库里的
脚本复现——`tests/benchmarks/` 里的断言就是本文表格的机器可读版本。

验证分三层，顺序不能颠：

1. **外部基准**：ACADS 1(a)——被商业软件与文献反复算过的标准题；
2. **内部恒等式**：不依赖任何外部软件就能严格证明的等式（φ=0、闭式解）；
3. **自洽性**：网格收敛、严格法的平衡闭合、方法间的相对次序。

---

## 1. ACADS 1(a) 基准题

参数（Giam & Donald, 1989）：

- 坡高 10 m，坡比 2H:1V，坡顶平台延伸至 x = 30 m；
- 均质土：\(c'=3\) kPa，\(\varphi'=19.6^\circ\)，\(\gamma=20\) kN/m³，无水；
- 标准滑弧：圆心 (0.03, 27.70)，半径 R = 27.69 m；
- 官方推荐答案 \(F=1.000\)。

| 方法 | slopestab | 文献值 | 偏差 |
|---|---|---|---|
| Fellenius（普通条分） | 0.9479 | 0.967（另一条滑弧） | 同量级，见 §1.2 |
| Bishop 简化 | 0.9854 | 0.987 (Slide2) / 0.992 (Zhao 2014) | −0.002 / −0.007 |
| Janbu 简化（未修正） | 0.9427 | — | 系统性偏低，符合预期 |
| Janbu 简化（\(f_0=1.05\)） | 0.9987 | 1.000（ACADS 官方） | −0.001 |
| Spencer | 0.9844 | 0.986 (Slide2) | −0.002 |
| Morgenstern-Price（half_sine） | 0.9841 | 0.986 (GLE, Slide2) / 0.991 (Zhao) | −0.002 / −0.007 |

复现：

```bash
python examples/01_quickstart.py
pytest tests/benchmarks/test_acads.py -m slow -q
```

### 1.1 偏差从哪来

不是拟合出来的巧合，主要来自几何面积：

- 该题滑动体面积按标准滑弧应为 47.174 m²（文献值）；本库在同一滑弧上积分得 **48.204 m²**，
  差约 2%。原因是坡面按折线离散、条底按直线近似，且标准滑弧在坡脚处的端点位置对面积敏感。
- 面积大 2% → 驱动力矩大 2% → Fs 低 2% 量级，正好解释了 −0.002～−0.007 的差距。
- 想更贴文献值，把 `n_slices` 提到 60–80 只能改善 0.0001 量级；真正的上限是条底直线假设。

所以本库把"±1%"写成验收线，而不是追求小数点后第三位。要复现商业软件的数，得改用
"条底按弧长真曲线积分"的写法，v0.2 再考虑。

### 1.2 Fellenius 的 0.9479

Fellenius 只做径向平衡，本身就偏低 5–15%；此处与 Bishop 差 3.8%，落在预期带内。
文献里的 0.967 是**另一条滑弧**的结果，不能直接对比，列出来只为说明量级。

## 2. 网格收敛

同一算例、同一滑弧，只改条数（Bishop）：

| n_slices | 10 | 20 | 30 | 40 | 60 | 80 |
|---|---|---|---|---|---|---|
| Fs | 0.9858 | 0.9854 | 0.9854 | 0.9855 | 0.9855 | 0.9855 |

## 3. 内部恒等式

### 3.1 φ = 0 时 Bishop 必须等于 Fellenius

\(\varphi'=0\) 时 \(m_\alpha=\cos\alpha\)，两法退化为同一个力矩方程，且 \(F\) 有解析解

\[
F=\frac{c\,L\,R}{\sum W_i\,(x_i-x_0)}
\]

用同一算例换成 \(c=40\) kPa、\(\varphi=0\)、\(\gamma=20\) kN/m³（沿用 ACADS 土的重度）检验：

| 量 | 值 |
|---|---|
| Bishop | 2.43710 |
| Fellenius | 2.43732 |
| 解析解 \(cLR/\sum W(x-x_0)\) | 2.43732 |
| Bishop − Fellenius | \(2.15\times10^{-4}\) |

Bishop 的残差来自定点迭代只收敛到 \(10^{-4}\)。这个检验的价值在于：它同时验证了
条重积分、条底长度、力臂与圆心位置四处几何，任何一处写错都会立刻破坏等式。

### 3.2 无限边坡对闭式解

干燥条件 \(F=c/(\gamma z\sin\beta\cos\beta)+\tan\varphi/\tan\beta\)，顺坡渗流
\(F=c/(\gamma_{sat}z\sin\beta\cos\beta)+(\gamma'/\gamma_{sat})\tan\varphi/\tan\beta\)：

| z (m) | 干燥（库） | 干燥（手算） | 渗流（库） | 渗流（手算） |
|---|---|---|---|---|
| 1.0 | 1.627 | 1.627 | 1.100 | 1.100 |
| 2.0 | 1.280 | 1.280 | 0.788 | 0.788 |
| 3.0 | 1.164 | 1.164 | 0.683 | 0.683 |
| 5.0 | 1.071 | 1.071 | 0.600 | 0.600 |

`critical_depth(26.57°, c=5, φ=25°, γ=18)` 得 10.27 m，与
\(z_c=c/(\gamma\sin\beta\cos\beta\,(1-\tan\varphi/\tan\beta))\) 一致。

这条检验的意义：无限边坡是本库唯一能与牛顿力学手算完全对上的模型，它把"重度取值、
角度单位、渗流重度折算"三个易错点钉死了。

### 3.3 Spencer 与 M-P（constant）必须重合

\(f(x)\equiv1\) 时 Morgenstern-Price 就是 Spencer。ACADS 上两者均为 0.984，λ 也一致；
均质坡上 1.4944 / λ=0.391 与 Spencer 完全相同。单测里对 Fs 与 λ 双断言。

## 4. 三组自编算例（无外部基准，看自洽性）

### 4.1 均质坡，H=10 m，2H:1V，坡顶/坡脚平台各 20/10 m

\(c=10\) kPa，\(\varphi=20^\circ\)，\(\gamma=18\) kN/m³，滑弧 (10.03, 27.70, 27.69)：

| 方法 | Fs |
|---|---|
| Fellenius | 1.4591 |
| Bishop | 1.4964 |
| Janbu（未修正） | 1.4413 |
| Spencer | 1.4944 |
| M-P（half_sine） | 1.4862 |

次序符合理论：Fellenius < Janbu < M-P < Bishop ≈ Spencer。Bishop 比 Spencer 高 0.13%，
在这种低孔压题里是正常现象（Bishop 忽略了条间剪力，通常略高或略低，取决于滑面形状）。

M-P 的 \(f(x)\) 敏感性（同一条滑弧）：

| \(f(x)\) | constant | half_sine | trapezoid | sine |
|---|---|---|---|---|
| Fs | 1.4944 | 1.4862 | 1.4871 | 1.4620 |
| λ | 0.391 | 0.578 | 0.463 | 0.274 |

`constant` 精确等于 Spencer 是本库最强的一条内部校验。

### 4.2 三层土 + 浸润线（M-P 的压力测试）

坡面 (0,0)→(10,0)→(30,10)→(50,10)；填土/黏土/基岩，层界 y=3、y=7；
浸润线 (10,0)→(30,9)→(50,9)；滑弧 (10.03, 27.70, 27.69)。

| 方法 | Fs | λ |
|---|---|---|
| Fellenius | 2.4392 | — |
| Bishop | 2.5438 | — |
| Janbu（未修正） | 2.3204 | — |
| Janbu（\(f_0=1.05\)） | 2.4460 | — |
| Spencer | 2.5542 | 0.415 |
| M-P（half_sine） | 2.5416 | 0.788 |
| M-P（constant） | 2.5542 | 0.415 |
| M-P（trapezoid） | 2.5400 | 0.606 |
| M-P（sine） | 2.4265 | 0.313 |

Bishop 与 Spencer 差 0.4%，与商业软件上这类题的常见差距一致。这个算例曾经把孔压项
漏写的问题暴露出来（Spencer 高出 Bishop 22%），现在作为回归算例留在示例 02 里。

`half_sine` 需要 λ=0.79 才闭合，比 Spencer 的 0.42 大一倍——这是 \(f(x)\) 形状的
真实影响，不是数值噪声。

### 4.3 拟静力与超载（示例 03）

同一均质坡，逐个工况：

| 工况 | Fs |
|---|---|
| 静力 | 1.6237 |
| \(k_h=0.10\) | 1.3120 |
| \(k_h=0.20\) | 1.0917 |
| \(k_h=0.20,\ k_v=0.10\) | 1.0922 |
| 坡顶 \(q=30\) kPa | 1.5466 |
| \(k_h=0.15\) + \(q=30\) kPa | 1.1463 |

量级校验：\(k_h=0.2\) 使 Fs 掉 33%，符合拟静力法的经验范围（每 0.1 的 \(k_h\)
大致掉 0.2～0.3 的 Fs）。\(k_v\) 取向下为正时 Fs 略降，方向约定与 USACE 一致。

## 5. 滑面搜索

均质坡（§4.2 的几何，\(c=10,\varphi=20,\gamma=18\)），`search_circular` Bishop：

| 项 | 值 |
|---|---|
| 临界 Fs | 1.4195 |
| 圆心 | (13.973, 21.644) |
| 半径 | 22.004 m |
| 试算 / 有效 | 4032 / 719 |
| 耗时 | 0.6 s |

搜索是**确定性**的：网格 24×14×12 固定，几何预筛固定，Nelder-Mead 精修取前 3 名固定
初值。同样输入永远同样输出，可写进 CI（`pytest -m slow` 里断言 Fs 在 1.42±0.02）。

精度说明：粗网格步长约 1 m，精修后圆心/半径能收到 0.01 m 量级；与商业软件的
"自动搜索"比，差异主要在网格范围（`SearchGrid.default` 由坡高推导，坡外 1.5H）而非算法。

## 6. 平衡残差

ACADS 1(a)、30 条：

| 方法 | $F_x$ (%) | $F_y$ (%) | $M$ (%) |
|---|---|---|---|
| Fellenius | +1.63 | −3.70 | 0.00 |
| Bishop | −1.80 | 0.00 | +0.03 |
| Janbu（未修正） | −4.38 | +16.86 | +210.4 |
| Spencer | −0.00 | −0.00 | +0.001 |
| M-P | 0.00 | −0.03 | −0.01 |

读法：

- Fellenius 只有力矩闭合，\(F_x\) 非零是定义使然；
- Janbu 只闭合水平力，力矩残差大得离谱是正常的（它就是简化法的代价）；
- 严格法两个方向加力矩都到 0，才敢叫"严格"。

benchmark 里对严格法的断言是"残差相对总重 < 0.05%"，取的是绝对值的量纲化版本
（`*_abs` 字段），避免小算例上被百分比噪声放大。

## 7. 已知的不一致与限制

| 现象 | 原因 | 处置 |
|---|---|---|
| 严格法只支持圆形滑面 | 非圆弧需额外假设条间力线位置；不做假设会给出 34% 偏差的假数 | 代码里抛 `GeometryError`，提示改用 bishop/janbu |
| Janbu \(f_0\) 不自动查表 | 图表依赖滑面形状，硬编码会误导 | 默认 1.0，须显式传值 |
| M-P 可能无 λ 解 | 某些 \(f(x)\) 就是无法同时闭合两个方程 | 最小残差 ≤0.02 时接受并标注 `converged=False` + `note`，否则报错 |
| 与商业软件差 1–2% | 条底直线近似、面积离散 | 文档明写，验收线 ±1% |
| 浸润线是静水压 | 不做渗流场 | 需先用其他工具算孔压后传入 |
| 浸润线画到地面以上 | 孔压会超过条重，有效法向力变负，Fs 失去意义 | 条分阶段直接抛 `ValueError`，报出具体 x 与 `u*b`、`W` 的数值 |
